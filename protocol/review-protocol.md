# Review protocol (Part 1)

One reviewer applies the same procedure to all 20 clips.

## Per clip

1. Open the clip and identify its `Clip ID`.
2. Preview the 12 sampled stills (0, 5, …, 55 s) and assign a clarity label:
   - `clear`
   - `moderately unclear`
   - `very unclear`
3. Start the review timer.
4. Review the sampled stills using `counting-rule.md`.
5. Enter the review information and stop the timer.
6. Record interruptions separately; interruption time is excluded from review time.

## Intended order versus actual execution

The intended protocol was to rate clarity before timing. In the final dataset, however, clarity was assigned after timing and after preliminary AI-assisted ratings had been seen. This deviation is documented in `data/README.md`, `decisions.md`, and the analysis as a major source of possible bias.

## Consistency

The same reviewer, screen/workflow, clarity definitions, and timing rule are used across clips. Review time excludes setup/file hunting and interruption time.
